## Descripción

Este proyecto desarrolla un análisis exploratorio de datos sobre **delitos sexuales en Colombia**, utilizando Python en un cuadernillo de Jupyter.  

El ejercicio incluye:

- limpieza y preparación de datos,
- análisis por departamento y municipio,
- identificación de municipios sin reportes en 2023,
- análisis de víctimas por género,
- identificación de días con mayor ocurrencia,
- evolución temporal de los casos,
- visualizaciones estadísticas,
- y una propuesta de mapa interactivo con tasas por población.

## Objetivo

Aplicar herramientas de análisis de datos para responder preguntas sustantivas sobre la distribución territorial y temporal de los delitos sexuales en Colombia.

## Cómo usar este repositorio

1. Haz clic en el botón **Open in Colab** para abrir el cuadernillo en Google Colab.
2. Ejecuta las celdas en orden.
3. Carga la base de datos correspondiente si no está incluida en el repositorio.
4. Revisa las tablas y gráficos generados para responder las preguntas del taller.

## Resultados esperados

A partir del cuadernillo se pueden obtener resultados como:

- departamentos con mayor número de casos,
- municipios con más reportes,
- proporción de víctimas por género,
- días del mes y del año con mayor frecuencia,
- evolución temporal de los delitos,
- e insumos para mapas por niveles y tasas.
